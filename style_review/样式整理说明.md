# 双电机原理图样式整理

按要求将可直接接到引脚的信号标签移至引脚端点，删除MCU页40段孤立的标签引出短线。功能导线与分支保留。

移除87处电源/地标签：MCU45处、公共电源4处、电机1和2各19处。使用77个真实电源符号替代，并将MCU密集供电引脚的10个重复标注合并至同名供电母线。VCC、AVCC、MCU_VDDA、5V、12V、DCBUS、PGND、AGND、GND、VREF等保留原网络名。使用从KiCad电源符号派生的StylePower项目库，已登记sym-lib-table。

原生KiCad导出五页polished.pdf。以修改前后XML网表逐项比较430个实际器件的值、封装和全部物理引脚连接集合，结果一致。parent_comparison.json记录对比结果。原有电路/ERC待处理项没有因这次画法整理而视为解决。

修改前五页备份位于baseline/。请重新打开工程读取磁盘新版本，避免旧编辑器内容保存覆盖。

本次使用源文件坐标和PDF文字边界检查；当前模型不支持图像输入，未声称逐页人工视觉验收。PDF供直接审阅。
