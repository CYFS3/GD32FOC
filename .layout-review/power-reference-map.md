# 公共电源与参考FOC整体布局对应

本任务仅生成映射和刚性布局计划；未连接IPC，未修改PCB、原理图或库。交付`power-reference-map.json`包含97个当前器件全部对应：POWER_SHARED页87个、MCU页LDO/电源10个。数据来自`q1-after.xml`完整网表、当前`placement-groups.json`元数据、`power.kicad_sch`以及参考原工程只读提取的`reference-coordinates.json`（每个源器件含原PCB坐标/层/焊盘及原理图型号）。当前U19型号矛盾已直接复核power页12030–12086行。

## 输入—母线—MOS的原始位置关系

源板边界x99.1235…199.1235、y79.8475…134.8475mm，100×55mm。97个电源器件中心范围x100.6985…164.123、y82.314…133.876mm。中心包络不包含器件壳体/机械外伸，不能作为新板框。

- 输入源CN3中心(110.668,90.569)，位于原板左上区域；Q1(120.193,87.267)、Q3(118.174,93.998)在其右侧上下分布。
- 两个大电解：源C4(130.423,90.696)、C3(141.148,90.696)，从保护电路向右排到MOS之前；DCbus瓷片分布在它们周围，含源反面器件时须按JSON层复刻。
- 高侧MOS Q5/Q6/Q7位于x153.086，y84.219/91.204/98.189；低侧Q8/Q9/Q10位于x166.167，同样的三行Y。其间母线瓷片和周围驱动小件应保持参考关系。
- 驱动源U7(146.932,109.365)在MOS阵列左下；12V LM5164源U2(130.965,105.6185)位于电解下方、驱动左侧。
- 5V源U5(114.219,105.1105)在12V降压左侧；VCC/AVCC LDO源U3/U4在(106.353,99.2035)/(110.223,99.2035)。
- 模拟参考源U6(161.582,128.161)在FOC采样/模拟区下方，不应把它当成左上公共输入模块的一部分强行移远。

## 推荐执行的刚性计划

1. 对公共电源97个器件和M1参考映射器件，使用**同一个**原板坐标变换：`T=(目标左上x−99.1235,目标左上y−79.8475)`。随后各器件仅做当前封装原点/零度方向的焊盘配准。不要给公共电源另加整体下移。
2. 第一层整体包含原参考的输入、保护、电解、各级降压与M1功率/驱动/采样。公共输入只保留一套，不复制第二套电源器件。
3. M2沿Y复制到M1正下方，X对应一致。不要武断用55mm节距：参考框高55mm，但当前模块含大通孔测试点及新增15件，现完整模块真实包络约70mm高，所以目前78.5mm节距可直接作为保守候选。若父agent重新整理外围测试点，须重新用实际双面包络检查后才能缩短。
4. 主控GD32及HSLink/显示不复制参考STM32区域。将这些非电源功能组布置到M2左侧/下部空余区域，保留局部簇；取消原先把全部208个共享器件整体下移的策略，避免283mm工作区继续扩大。
5. 作为初步占用估计，完整源power+M1仍遵循100×55mm原关系，第二FOC下移后约100×(55+实际节距)mm再按新增主控/接口真实尺寸扩展；这不是板尺寸承诺，不新增板框/层叠。

## 执行限制

当前CN1公母变化、5012真通孔测试点、部分标准库封装与参考导入几何不同，必须按真实焊盘拟合和两面间距检查。不能因同型号值就保证机械相同。当前U19 Value/MPN不一致已记录，布局映射不代表器件选型核定。参考局部未使用器件不自动补入。此JSON只给摆放及证据，不复制铜线、过孔、铺铜、板框、层叠或原STM32。
