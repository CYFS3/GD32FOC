# 532封装初版IPC布局执行

已通过KiCad 10.0.6官方kicad-python IPC完成当前GD32F5_FOC.kicad_pcb的全部532个导入封装摆放，并以board.save保存。初始导入先保存并复制备份：`.layout-review/board-before-placement.kicad_pcb`；原始实际位置、bbox和各焊盘net记录于`live-before.json`。

## 范围与方法

18个功能组，初版软包络170×120mm：两套功率桥在上部、共享输入/降压在左、主控中下、HSLink左下、显示/按键右下。两个三相MOS阵列采用相同锚点结构，采样区名义10mm高度扩大至24mm；43个器件为避碰超出原分区矩形但仍在整体包络内。

关键芯片/连接器先放；U1实际8/9/12/13焊盘位于芯片左边，晶体据此放置。栅阻/自举/晶体等局部簇以真实焊盘为吸引点。其余所有器件以小网络邻接加权目标和最近可用位置搜索摆放，不是只摆关键件；大供电/地网不作为无差别吸引。M2同号偏移对应件优先复用M1相对坐标。

采用不含文本的IPC get_item_bounding_box，候选保留0.35mm轴向bbox间隔。全体移动一个可撤销事务，随后14个MCU/晶体电容进行一次pad距离微调作为第二个可撤销事务。未删除、克隆或新增PCB器件；未布线、未放过孔、未铺铜、未创建板框或安装孔、未改层叠或锁定状态。
