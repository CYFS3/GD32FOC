# 参考FOC测试点只读审计

本轮直接解析参考原PCB、原理图及其实际封装库，并解析当前PCB/六页原理图；没有接入IPC或修改任何电路、封装库、PCB。映射索引来自foc-reuse-map.json，但几何结论独立来自源文件。

## 结论

用户指出测试点不对有直接证据支持。先前把所有5012属性符号统一换成官方Keystone通孔机械封装，是一种依据采购型号的设计选择，**不是参考PCB的真实几何复刻**。该选择把参考直径1.27mm焊盘变成直径2.8mm、钻孔1.6mm、装配圆直径4mm的通孔端子，引发了后来多处避让和背面冲突。

但原始参考本身也存在属性矛盾：原理图是Value/Manufacturer Part=5012、Manufacturer=Keystone、Supplier Part=C2906766，Footprint指向不存在的中文“测试点”；实际PCB/库使用另一个 `TESTPOINT-TH_BD2.0_C9900010656`。实际库名含TH、Fab圆和User.1约1mm孔状多边形，drill却仅0.001mm。因此**不能证明原作者有意采用无孔表贴测试铜点**，也不能把0.001mm当作可制造机械钻孔。

按用户要求纠正并恢复参考小焊盘布局，合理方案是明确采用“直径1.27mm裸铜测试点”作为当前设计功能：保留源焊盘中心与大小，单面F.Cu/F.Mask，无钻孔、无F.Paste、不装机械端子。同步Value改为TestPoint，清除Keystone/5012/C2906766/相关采购和Datasheet身份及5012机械3D模型，设置不进入采购BOM。它是解决源属性矛盾的明确设计选择，不是宣称源文件已经证明为SMD。

若实际仍要求购买安装Keystone 5012端子，应保留匹配厂商机械的通孔模型与空间，接受布局不能等同参考小焊盘。不能同时保留5012采购身份又声称为裸铜测试点。

## 建议实施边界

1. 若按参考裸铜功能修正，52项都使用统一参考直径1.27mm的新本地模型，所有pin1网络保持；无孔，不复制无意义0.001mm孔或User.1孔图形为真实孔。
2. 裸铜点不需贴片焊膏。Courtyard可以保留源2.075mm方框用于探针空间，但这是参考空间而非5012机械壳体；恢复铜尺寸不意味着所有courtyard告警自动消失。
3. 模块测试点恢复源相对坐标，撤销因大5012而引入的测试点避让。变更5→6pin接口CN5的差异仍独立存在，不能一起撤销。
4. 电源输入+驱动整体源布局的坐标复刻应包括已核共享电源器件，不仅此前M1/M2页；第二路保持在第一路正下方。
5. 以上为审计建议，尚未改原理图/库/PCB。报告与JSON保留源完整属性，以便后续修复有据可查。
