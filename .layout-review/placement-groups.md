# 双路FOC初版布局计划

此文件及 `placement-groups.json` 只定义布局意图、分区矩形与关键中心种子，不操作IPC、不修改原理图或PCB，也没有生成板框、层叠、安装孔或布线。

数据来源为 `.layout-review/annotation-final.xml`（532个实体器件）和当前六页原理图的Value、Footprint、MPN、DNP属性。多单元U10/U1010按一个实体封装计数。当前Q1已是 `VerifiedParts:WSD90P06DN56_GDS123`，覆盖旧网表空封装元数据；网络仍以annotation-final.xml为准。参考为 `reference-layouts.md` 和其引用的 `reference-coordinates.json`；未找到同名reference-layouts.json，不影响读取实际报告。

## 关键摆放意图

- 电源入口CN1在左上西边；Q1/Q3随后，两个220µF罐及共享母线在其右下。受保护DCBUS/PGND分两路去两套桥，不让第二路功率回流穿过第一路或主控区域。
- 两套FOC置上半部，三相横向排列。每个单元高侧MOS中心初值y18、低侧y29，列距17mm；三个分流器y31，母线分流器靠共同回流端。每相本地DCBUS瓷片按换流环路分散，而不是都收成远离桥的整齐一排。
- CN41/CN1041的目标中心位于上边缘附近，插接面朝北的方向要检查实际MR30焊盘、外壳凸出和相序，JSON不强制角度。
- U7/U1007驱动位于各功率阵列下方，优先输出朝门极。每路自举电容按VB/VS脚贴近，不照搬参考的长距离。门极阻容二极管按对应MOS归为局部cluster，实际应摆在门极附近，而不是通通贴驱动器。
- U10/U1010位于功率区下方的安静采样条带。低侧/总线分流电阻的测量端走Kelvin对；反馈元件靠运放，不穿相节点铜皮或门极回路。NTC虽功能归采样，关键中心种子靠MOS区，后续按热耦合位置调整。
- U1为14×14mm LQFP100，种子中心(88,94)。Y200/Y201只是暂定种子，必须读实际U1焊盘8/9/12/13后与主控一起旋转、重新贴近；不可复制参考STM32 LQFP64的晶体位置。
- U1去耦给出逐电源脚cluster，VBAT.6、VDDA.22、VREFP.21分别就近。C200–204可按最近VDD脚重新排列，不以器件中心距离替代回路检查。
- HSLink沿西下边：USB8002→D8005→U8006，再围绕供电脚分配去耦。U8007是4.7µH电感，靠DCDC_LP；X8002靠35/36脚；USB口必须以实际壳体开口朝外对边。
- FPC300及SW300–302放右下，保证插线和按键访问；M1/M2编码器接口分在主控左右外侧，缓冲器与滤波处于接口和主控之间。

## JSON使用方法

`ref_to_group`覆盖全部532个实体ref，一次且仅一次。`components`包含当前value/MPN/footprint、DNP、sheet和实际pin→net；`groups`包含18个矩形及ref列表；`key_targets`给主要器件中心种子，rotation均null且locked=false；`local_clusters`给晶振、去耦、门极、自举、USB等依赖关系。

主agent应先读取导入PCB的真实bbox/courtyard及pads，确认导入ref集合与JSON差异。关键器件先放，随后按局部cluster和实际焊盘自适应填充。初始courtyard外额外1mm只是摆放余量，不是电气间距或安全爬电要求。DNP器件仍占位置，测试点应有探针/测试夹空间。未做热、压降、EMI、绝缘或DRC证明。

本计划不固定叠层、铜厚或安装孔。连接器朝向与母线极性仍需看实际pad和实物定义；仅按现网络为初版布局，不解除先前CN1极性核对项。完成初版摆放即符合本阶段范围，无需自动布线。
