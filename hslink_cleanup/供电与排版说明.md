# HSLink系统供电与排版修改

本版按要求让板载HPM5301调试器由系统VCC供电，取消独立TPS563201DDCR稳压级及其外围，并删除USB VBUS至板内电源的CH213K通路。USB VBUS保留连接器和ESD参考连接，不与系统5V或3.3V并接。

供电路径：系统5V → 原有U20 XC6210B332MR → 系统VCC3.3V → R8052 → HSL_LINK_3V3 → HPM5301 I/O及内部电源输入。HPM5301内部降压所用U8007电感与HSL_VDD_SOC去耦保留，不能把内核电源直接并到3.3V。

单插USB时调试器不工作，必须给系统供电。用户未指定要USB单独启动整板，本版不增加USB/系统电源自动切换或并联供电。

系统3.3V增加HPM5301负载后需核算U20电流和散热。芯片标称输出电流不代表实际封装/板级热条件下均可持续输出；例如5V降到3.3V，总负载300mA时LDO损耗约0.51W，该例仅说明计算方法，并非测得板上电流。当前没有实测HPM5301运行固件负载，不能确认系统稳压器余量。

默认DNP的R8901..R8905及原SWD/复位/UART连接保持。两侧共用系统供电降低了独立上电带来的风险，但外接调试器并用、不同供电时序和固件高阻仍需处理，因此没有擅自取消断开位。固件兼容性/烧录仍未验证。

排版采用A2页，将USB、HPM核心、去耦、调试转接、目标连接位、说明分区，清理标签文字重叠，电源保留真实电源符号。PDF文字边界检测中，HSL标签与其他不同文字的重叠候选从75处降为0；这不是整板制造或人工目视验收。最终图纸after.pdf，供电及保留电路的8项验证全部通过，详见verification.json。全工程ERC仍有828项（186错误、642警告），未宣称通过。修改前HSLink页备份HSLink.before.kicad_sch，原工程其他电路保持。
